# Sustainable Catalyst Research Librarian

A guided WordPress Research Librarian assistant for Sustainable Catalyst platform navigation.

## Purpose

The Research Librarian helps visitors find the right Sustainable Catalyst starting point: demos, modules, repositories, methodology, feature suggestions, article maps, and learning pathways.

## WordPress shortcode

```text
[sustainable_catalyst_research_librarian]
```

## Current version

Version 0.1.0 is deterministic and scoped. It does not call an external AI API and does not store visitor input.

## Boundaries

This is a navigation and learning assistant. It does not provide legal, financial, investment, medical, mental health, tax, compliance, assurance, ESG/SDG certification, or professional advice.
