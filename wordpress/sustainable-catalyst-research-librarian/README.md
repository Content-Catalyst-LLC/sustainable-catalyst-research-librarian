# Sustainable Catalyst Research Librarian

A lightweight WordPress plugin that provides a guided navigation assistant for Sustainable Catalyst demos, modules, repositories, methodology, feature suggestions, and learning pathways.

## Shortcode

```text
[sustainable_catalyst_research_librarian]
```

## What it does

The Research Librarian helps visitors choose a starting point:

- Catalyst Canvas for problem framing
- Catalyst Data for measurement and evidence records
- Catalyst Analytics R for scenario analysis
- Global Impact Catalyst for impact measurement
- Narrative Risk for claim review
- Catalyst Finance for tradeoff analysis
- Catalyst Grit for recovery tracking
- Methodology for operating standards
- Knowledge Library for article maps and learning paths
- GitHub for repositories and code
- Feature Suggestions for improvement ideas
- Consulting for applied support

## Boundary

This plugin is a navigation and learning assistant. It does not provide legal, financial, investment, medical, mental health, tax, compliance, assurance, ESG/SDG certification, or professional advice.

## Privacy

Version 0.1.0 runs in the browser. It does not send user questions to an external AI API and does not store visitor input.
